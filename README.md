# 想法梳理与商业研究 Skill

将碎片化商业想法，经逐轮需求访谈、公开研究、可行性与资金分析、真实验证准备，整理成商业计划、行业报告和分板块视觉材料。

## 安装

复制本仓库的 `idea-to-business` 文件夹到 Codex 当前配置的 skills 目录。

```text
$idea-to-business 我有一个零散商业想法，请先分轮了解目标和约束，确认需求后再展开研究。
```

完整安装方法、依赖、工作流程、测试说明及已知限制，请阅读 [使用指南](idea-to-business-guide.md)。

## 核心规则

- 先访谈和确认需求，再研究与制作；区分事实、估算、假设和待验证事项。
- 公开研究、问卷设计和财务测算不能冒充真实市场验证。
- Codex 负责研究与报告，图片按用户指定通过 ChatGPT 普通聊天协作；五版共用已确认内容，设计各不相同。
- 发送结果未知时先恢复状态与文件，禁止自动重复发送；选版和反馈修改保留用户确认。
- 不附带登录会话，不保证所有环境都能自动取图，也不承诺免费。
